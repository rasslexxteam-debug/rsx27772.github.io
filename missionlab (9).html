      First-time setup
        
        
          
      1. Pybricks firmware on the hub
            
        If your hub already runs Pybricks, skip this. Otherwise install it once with the official installer: open code.pybricks.com, Settings, “Install Pybricks Firmware”. After that you never need Pybricks Code again; MissionLab uploads and starts programs itself. Pybricks v3.3 or newer is needed.
        2. 
          
      2. Use Chrome or Edge
            
        Bluetooth from a web page works in Chrome or Edge on a computer or Android, not on iPhone. If “Connect hub” says Bluetooth is blocked here, download MissionLab and open it from its own web address. MissionLab needs internet the first time it uploads, to load the Python compiler.
        
            
        3. 
          
      3. Connect and upload
            
        Turn the hub on, close Pybricks Code and the SPIKE app, press “Connect hub” and pick the hub. ▶ on any run uploads the program if needed and starts that run.
        4. 
        
      
      
      
      
      The program
      
      
      Pybricks Python built from your Steps and Robot settings with your LQR drive and turn functions. MissionLab compiles and uploads it for you.
